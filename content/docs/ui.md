# CAGE UI

CAGE UI is a retained application model. `🖥️` declares a surface, `🪟` a window, `🧱` a panel or region, `🏷️` a label, `🔘` a button, and `📝‍💻` an editor.

Pointer input uses `🖱️` and editor/keyboard input uses `⌨️`. Interactive controls are required to resolve to real CAGE actions rather than host-only placeholders.

A source-authored UI transaction begins with the transaction vocabulary around `🧿`. Current UI operations include text mutation `✏️`, style/render mutation `🎨`, metric updates `📊`, animation `🎞️`, notification `🔔`, and scene additions.

The V4 editor command registry also includes Copy `📋`, Paste `📥`, Cut `✂️`, Delete `🗑️`, Rename `✏️`, New file `📄➕`, New folder `📁➕`, Run `▶️`, Pause `⏸️`, and Stop `⏹️`.
