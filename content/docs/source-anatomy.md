# Source anatomy

A strict CAGE V4 file is a layered legal document. It begins with the V4 envelope and Constitution revision, declares module identity and proof evidence, then reaches executable resources, functions, and optional UI.

Blocks open with `🧰`, close with `🔒`, and declarations commonly end with `🔸`. Text payloads use `📝` and `🛑`; numeric literals use `🔢` with keycap digits.

Formatting and declaration order can be semantic. CAGE does not assume that rearranged source has the same legality.
